# Walkthrough

This walkthrough will guide you through the basic steps for setting up the build system and writing your first test.

This walkthrough requires you to know a bit of Rust. If you have never programmed in Rust before, we recommend going through [The Book](https://doc.rust-lang.org/book/).

We based the walkthrough  on the [GPIO example](https://github.com/pileghoff/cesty/tree/master/examples/gpio).

If you want a more direct and less hand-holdy introduction, skip the walkthrough and go directly to the [Concepts](../concepts.md) section.
